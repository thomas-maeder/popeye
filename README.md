## Popeye

Popeye is a free open-source cross-platform program for testing chess problems.

It can be used for orthodox problems, but also supports a great deal of fairy
chess elements (piece types, conditions and stipulations).

Thanks to its "intelligent mode", Popeye is very fast at testing (almost) orthodox
help and series (stale)mate problems.


## A bit of history

Popeye was started in the 1980s by Philippe Schnoebelen in some Pascal dialect.
It was later converted into C by Norbert Geissler.
Development of most features has been done in C.


## Portability

Popeye can be easily compiled using make and e.g. gcc for Linux and other Unix-oid
operating systems. Depending on the availability of cross-compilers, executables for
Windows and MacOS are provided for released versions.

Popeye is known to have been compiled for other platforms, e.g. Android or WebAssembly.


## Companions

- [Olive](https://github.com/dturevski/olive-gui) is a great cross-platform GUI for Popeye
- [Teddy](https://problemskak.dk/download-Teddy.php) is a popular Windows GUI for Popeye
- [FEN Tool](https://mutsuntsai.github.io/fen-tool/) allows using Popeye within the browser, both on mobile phones and regular computers
- [Spinach] (experimental) speeds up Popeye by distribution its workload on different CPU cores
